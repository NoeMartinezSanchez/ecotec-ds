# sitec-ti.gt.tc — Sitio Web Corporativo

Sitio web institucional desarrollado con HTML, CSS y JavaScript.

## Tecnologías
- HTML5
- CSS3
- JavaScript (Vanilla)

## Estructura
- `index.html` — Página principal
- `css/` — Estilos
- `js/` — Scripts
- `images/` — Recursos gráficos

## Despliegue
El sitio se aloja en **Netlify** con despliegue automático desde GitHub.
Cada `git push` actualiza el sitio en producción automáticamente.
